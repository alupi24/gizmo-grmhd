# Phase-0 projection comparison: N = 32^3, N_ngb = 32, limiters ON

Static test of the localized divergence projection (divfree/hydro/docs/LOCAL_PROJECTION_notes.pdf) with GIZMO's MFM faces, gradients and limiters replicated in Python (flat space). Generated by `phase0_projection.py`.

## Definitions

- `div` = rms_i( dx_i |D_i| / V_i ) / rms|B|, with D_i the face-sum divergence the hydro loop accumulates (dx_i = V_i^(1/3)).
- `reduction` = div(no projection) / div(variant), same gradient type.
- `face`: divergence-free fields (uniform, tg3d, abc): rms over faces of |B_face.n - B_exact(x_mid).n| / rms|B| (face reconstruction error); gradient fields (grad_short, grad_long: B = B0 + grad(phi)): rms|B_face.n - B0.n| / rms|grad(phi)(x_mid).n| (fraction of the gradient part left, 1 = untouched, 0 = removed); bump (GIZMO monopole-like): rms|B_face.n - B_bump(x_mid).n| / rms|B| (how much the faces were changed).
- `incr max / p99`: largest and 99th-percentile face increment |c_i| |D|^2 |A| relative to the local field scale max(|B|) over the stencil (what a cap would have to allow); `n(B=0)`: particles with a non-zero increment where the local field is exactly zero.
- `cost` in pair-pass equivalents (PPE): one pass over all pairs with face evaluation, i.e. one constrained-gradient-type iteration. Jacobi K sweeps = K (the first sweep is fused with the pass that computes D); star = 2; stencil = 1 + (intra-stencil pairs)/(pairs) per pass; exact = 1 + PCG iterations.
- gradient `std`: GIZMO MLS gradient with the per-row limiter; `tl`: traceless projection G - tr(G)/3 I with a single scalar limiter factor (keeps tr G = 0).
